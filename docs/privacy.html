Privacy policy

Effective date: November 19, 2026

Arcflow adapts Chrome navigation for people familiar with Arc. It provides a left-side tab sidebar, command bar, tab organization, download and extension controls, and optional page styling. On a new installation, Arcflow stays off until you review the onboarding notice and choose to enable it. This policy describes the information the extension accesses after activation, how it is used, and when information leaves your device.

Information Arcflow accesses

  • Open tab titles and URLs (browsing activity): Used on your device to display and search tabs, switch between them, navigate, and organize tabs into Chrome groups and nested folders. Titles and URLs can sometimes contain personal details, such as a name, email address, or information included in a URL.
  • Current page title, URL, and clicked link destination: Used by in-page controls and when you invoke URL copy, search, or navigation features. When you use a supported link-opening gesture, Arcflow reads that link's destination to open it in a new tab. Arcflow does not read page body text, images, media, form entries, or page storage.
  • Download details: When you open the downloads interface, Arcflow reads Chrome download records such as file names (which may include a local file path or identifying details), status, dates, size, and progress so it can display and search them locally. It opens or reveals a file only after you choose that action.
  • Installed extension details: Arcflow reads installed extension names, identifiers, versions, options pages, and available icons to show extension information in its interface.
  • Preferences and workspace organization: Appearance, feature preferences, and the workspace name use Chrome Sync storage and local extension storage. Nested-folder parent relationships and short-lived recovery state are stored locally. A temporary recovery record may contain the failed page URL and network error; it is used only to render the recovery screen and is cleared when its tab closes.

How information is used

Tab titles and URLs are processed in Chrome to provide the sidebar, tab search, switching, grouping, pinning, moving, and closing controls. Link destinations are read only when you use a supported link-opening gesture. Click, keyboard, and pointer events are handled transiently to operate controls and reveal the sidebar; Arcflow does not record or retain an interaction log. Download details and installed extension information are read only when you open their corresponding panels. Content scripts add Arcflow’s interface and optional page framing on eligible websites; they do not read page body text, images, media, form entries, or page storage. The settings interface can open in an embedded panel over the active page; it loads extension-packaged UI and uses the same settings described here without reading page content. The extension can display a favicon URL supplied by Chrome for a tab; displaying it may cause a request to that favicon’s host. Arcflow does not use a centralized favicon lookup service.

Arcflow does not operate an analytics or browsing-data server. The extension does not send tab titles or URLs, clicked link destinations, download records, interaction logs, or extension inventory to the developer. Search text is kept temporarily in the interface while you use it and is not saved as a search history. When you submit a search, Chrome navigates to the provider selected in Arcflow’s settings; that provider receives the query as part of the normal browser request. When a favicon URL supplied by Chrome is displayed, the favicon host may receive a request from the browser. If Chrome Sync is enabled, Chrome may synchronize Arcflow preferences and workspace name through your Google account.

Sharing, sale, and advertising

Arcflow does not sell user data, use browsing information for advertising, or transfer it to data brokers. The extension does not provide user data to the developer. Browser requests to a favicon host and the search request you submit go to those service operators as part of rendering an icon or carrying out your search; Chrome Sync may transmit preferences and workspace name when enabled. Those services are governed by their own policies and settings.

Retention and deletion

Arcflow does not maintain a developer-side copy of your browsing activity. Preferences and the workspace name are kept in Chrome Sync and local extension storage; nested-folder relationships and temporary recovery records are kept locally. Local extension data is removed by Chrome when the extension is uninstalled. Synced preferences can be managed in your Chrome and Google account settings.

Permissions and site access

Arcflow requests storage for preferences, the workspace name, nested-folder relationships, and temporary recovery state; tabs and tabGroups to display and organize tabs; sessions to restore recently closed tabs or windows when requested; webNavigation to detect eligible navigation errors for recovery; downloads and downloads.open to display, search, reveal, or open downloads after your action; scripting to add its interface and styling to eligible tabs; and management to show installed extension information. Broad website access is used so the sidebar, command bar, shortcuts, and optional page styling can work across websites. Chrome internal pages and other browser-restricted pages are not accessible to content scripts.

Limited use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Arcflow’s use and transfer of information received from Chrome APIs is limited to providing the user-facing browser features described in this policy. Arcflow does not use this information for advertising, sell it, or transfer it to data brokers. The extension has no developer-operated service that receives this information. The developer does not access it, except when you choose to include information in a support request or when disclosure is required by law.
